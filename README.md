# High-End-Sites

High-end statická landing page pre **LIGLES s.r.o.** zameranú na pilčícke a manipulačné práce v lese.

## Obsah

- responzívna jednostránková prezentácia,
- sekcie služby, štandard práce, informácie o firme a kontakt,
- prémiový vizuálny štýl bez externých build nástrojov,
- čisté HTML, CSS a JavaScript súbory pripravené na GitHub Pages.

## Spustenie lokálne

Nie je potrebná inštalácia závislostí. Stačí otvoriť `index.html` v prehliadači.

Voliteľne cez jednoduchý lokálny server:

```bash
python3 -m http.server 4173
```

Potom otvoriť `http://localhost:4173`.
